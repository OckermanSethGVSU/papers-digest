# Vector Search Digest — 2026-11-19

## Highlights

- **[Errpedia: Is Your Exact $k$-NN Vector Search Really Exact?](http://arxiv.org/abs/2611.22474)** — Every one of 20 tested library and database configurations returned mathematically wrong top-10 results, which casts doubt on the brute-force ground truth behind every recall number you report; the test suite is cheap to add to CI.
- **[UniGraph: A Unified Graph-based Index for Dynamic Hybrid Dense-Sparse Vector Retrieval](http://arxiv.org/abs/2611.20758)** — A production-deployed design for a single bounded-degree graph that serves dense+sparse hybrid queries at arbitrary per-query weights, replacing the two-index-plus-rerank pattern most engines ship today.

## Graph indexes beyond single dense vectors

### [UniGraph: A Unified Graph-based Index for Dynamic Hybrid Dense-Sparse Vector Retrieval](http://arxiv.org/abs/2611.20758)
_Keyu Chen, Xiaoyao Zhong, Jiabao Jin et al. | 2026-11-16 | arXiv (cs.IR) | ⭐⭐⭐_

Builds one bounded-degree proximity graph by merging the neighbor sets computed under several dense/sparse hybrid weights, so queries with any weight can search without rebuilding the index. Search picks a sparse- or dense-guided entry point based on the query weight, and a dense-first pruning step skips exact sparse distance computations. It reports 27.6–52.3% higher QPS than the fastest baseline at Recall@100 ≥ 0.95 and is deployed at Ant Group.

**Vector search angle:** The multi-weight neighbor merge, the weight-dependent entry-point choice, and computing the cheap dense distance before the sparse one carry over directly to any engine that currently fuses separate dense and sparse HNSW/inverted-index results.

### [SIMQ: A Single Graph-based Index for Multi-Vector Query](http://arxiv.org/abs/2611.22079)
_Yifan Lu, Jiabao Jin, Xiaoyao Zhong et al. | 2026-11-17 | arXiv (cs.IR) | ⭐⭐⭐_

Clusters all ColBERT token vectors using data-aware sampling, builds a single graph over the cluster centroids, and approximates MaxSim with per-token graph searches instead of PLAID's centroid-interaction matrix. The authors prove data-aware cells have lower expected approximation error than data-oblivious partitions. SIMQ+ adds count-based scoring and a dynamic candidate set, and the method is integrated into the VSAG library.

**Vector search angle:** Shows a CPU-only route to late-interaction retrieval that reuses an existing single-vector graph index over centroids, so multi-vector support does not need a separate PLAID-style engine.

### [Pelorus: Warped-Product Graph Indexing for Hyperbolic Vector Search](http://arxiv.org/abs/2611.22159)
_Wenxuan Xiao, Xu Cao | 2026-11-17 | arXiv (cs.DB) | ⭐⭐⭐_

A proximity-graph index for hyperbolic embeddings that keeps radial and conformal scalars in FP32, stores directions as 2-bit spherical codes, and reranks a small candidate tail at FP64. Edges are pruned by a new rule (QuadriPrune) that spreads them across radial and same-shell neighbors, with tree-based repairs so the entry point can reach every node. Nodes are stored as single-page records and scored with an AVX2 kernel. On Cohere-1M it builds 5.44x faster and gets 4.3–6.3x higher throughput at 99% Recall@10.

**Vector search angle:** The split into full-precision norm/scale scalars plus low-bit direction codes is a reusable compression recipe, also relevant to MIPS where norms matter, and the per-region edge budgeting is a concrete pruning idea.

### [CapCover Filter: Semantic Approximate Membership Queries over Embeddings](http://arxiv.org/abs/2611.20132)
_Dvir David Biton, Shay Hahiashvili, Nadav Keren et al. | 2026-11-15 | arXiv (cs.DB) | ⭐⭐⭐_

A spherical-cap summary of an embedding set that can reject threshold queries with no qualifying neighbor, with no false negatives and no dependence on the threshold. At cosine 0.95 it avoids 20–100% of index accesses using 2% of the FP32 memory. Placed in front of a FAISS flat index it raises range-search throughput by 116% on average.

**Vector search angle:** A cheap pre-filter for range and threshold queries (dedup, semantic caches, guardrails) that could be attached per partition or per tenant to skip IVF lists or whole shards.

## Quantization and compact codes

### [Computed Permutation Trellis Coding: Near-Optimal Quantization from Two Multiplications and a 64-Byte Table](http://arxiv.org/abs/2611.22019)
_Muhammed Fatih Balın | 2026-11-17 | arXiv (cs.LG) | ⭐⭐_

A trellis-coded quantization format whose decoder needs only two multiplications and a 64-byte lookup table. One decoder covers 1–6 bits and comes within 0.07 bits of the information-theoretic ideal at 4 bits, matching codes with tables thousands of times larger. It beats QTIP codebooks on Llama weight quantization and ships in AWS Trainium 4 hardware.

**Vector search angle:** Write-once, read-many is exactly the vector store access pattern, and a 64-byte table fits in SIMD registers, so this is a candidate for near-optimal 2–4-bit vector codes beyond scalar quantization if trellis decoding can be fused into distance kernels.

### [MiSTiQ: MicroScaling Trellis Quantization for Extreme KV Cache Compression](http://arxiv.org/abs/2611.21216)
_Ofir Gordon, Lior Dikstein, Paul Balanca et al. | 2026-11-16 | arXiv (cs.LG) | ⭐⭐_

Replaces codebook vector quantization of KV caches with trellis coding plus beam-search encoding. Hash functions emit reconstruction values directly in microscaling (MX) formats such as NVFP4, so attention runs in low precision without dequantizing. It reaches about 1.25 bits per element with better perplexity and accuracy than prior methods.

**Vector search angle:** Shows how to get large effective codebooks without storing them while decoding straight into hardware-native FP4/FP8 formats, which points toward GPU vector search that scores compressed vectors on tensor-core formats.

### [HADVQ: Hessian Aware Directional Vector Quantization](http://arxiv.org/abs/2611.22721)
_Daniil Li, Mars Davletshin, Vadim Klyzhenko et al. | 2026-11-17 | arXiv (cs.LG) | ⭐⭐_

An ultra-low-bit LLM weight quantizer that first applies a random rotation, then quantizes magnitudes and directions separately. Directions use a structured codebook built on the E8 lattice. A small set of sensitive channels, found with a proxy Hessian, is kept at higher precision for 0.16 extra bits.

**Vector search angle:** Random rotation plus a lattice codebook for directions and a separate norm is closely related to RaBitQ-style designs, and E8 direction codes are a drop-in idea for compressing normalized embeddings.

### [Leveraging Binary Hashing for Scalable Index Assignment in Semantic Communications](http://arxiv.org/abs/2611.21260)
_Leonardo Roque, Kuangyun Zhu, Louis-Adrien Dufrène et al. | 2026-11-16 | arXiv (cs.IR) | ⭐_

Compares random LSH with PCA-, CCA- and ITQ-based binary hashing for sending text embeddings over a noisy channel. Data-dependent hashing beats random LSH, ITQ refinement adds robustness to bit flips, and CCA-ITQ gives the best downstream classification.

**Vector search angle:** Gives a recent MTEB-embedding comparison showing learned rotations (ITQ) beat sign-of-random-projection binarization, which is relevant when choosing a binary quantizer.

### [Practical Semantic Communication for General-Purpose Networks: Compression of High-Dimensional Embeddings Under Quantization](http://arxiv.org/abs/2611.20863)
_Leonardo Roque, Louis-Adrien Dufrène, Quentin Lampin et al. | 2026-11-16 | arXiv (cs.LG) | ⭐_

Derives a task-aware linear compression matrix for text embeddings from a relaxed Gaussian Information Bottleneck, with closed-form gradients. It adds bounds linking continuous embeddings to quantized, noisy ones. At low bit budgets it outperforms task-agnostic quantization on classification.

**Vector search angle:** A closed-form, supervised alternative to PCA for reducing dimension before quantization, though it optimizes classification rather than neighbor preservation.

### [CARE: Contrastive-Anchored Residual Encoding with Listwise Reconstruction for Retrieval-Oriented Semantic IDs](http://arxiv.org/abs/2611.20721)
_Yuan Xu, Dawei Chen, Xiaoguang Lin et al. | 2026-11-16 | arXiv (cs.IR) | ⭐⭐_

Trains a residual alignment network with a query-document contrastive loss before residual quantization, then distills each query's listwise similarity distribution into the reconstructions. Both tokenizers achieve higher recall than residual k-means, and the paper finds the choice of embedding matters far more than the choice of quantizer. It is deployed for generative video search.

**Vector search angle:** Query-aware residual quantization, judged by the recall of both the partition and the reconstruction, is directly applicable to training IVF and RQ codebooks for query-to-document rather than document-only distortion.

## Clustering for partitioning and drift

### [Two Counterexamples for e-means](http://arxiv.org/abs/2611.22065)
_Zhenisbek Assylbekov | 2026-11-17 | arXiv (cs.LG) | ⭐⭐_

Gives two constructions where the published e-means recipe (exponential averaging plus cluster revival) ends with higher loss than Lloyd's algorithm from the same initial centers. Mass-based revival can destroy a global optimum, and the ratio of expected losses can be unbounded even with k-means++ seeding.

**Vector search angle:** A caution before swapping e-means into IVF or PQ codebook training: check its revival step on your data against a Lloyd baseline.

### [When is Uniform Sampling Optimal? Coresets for Distributional Clustering](http://arxiv.org/abs/2611.20641)
_Junqiu Hu, Lingxiao Huang, Baoduo Xu | 2026-11-16 | arXiv (cs.DS) | ⭐⭐_

Shows that for balanced isotropic Gaussian mixtures, plain uniform sampling yields strong k-means coresets of near-linear size Õ(kε⁻²), beating the worst-case bound. A matching lower bound shows uniform sampling cannot do as well for anisotropic mixtures.

**Vector search angle:** Gives theoretical cover for training IVF centroids on a uniform subsample, and a warning that strongly anisotropic embedding distributions may need importance sampling to keep partitions faithful.

### [How Much Distribution Shift Can a Clustering Withstand? Exact Split and Merge Certificates for Structured Transports](http://arxiv.org/abs/2611.22000)
_Alisina Bayati, Srinivasa Salapaka, Shahriar Talebi | 2026-11-16 | arXiv (cs.LG) | ⭐_

Uses phase-transition stability from deterministic annealing to define when a distribution shift forces a cluster to split or two clusters to merge. For shifts restricted to a subspace it computes exact split and merge radii as small SDPs, giving a robustness certificate for a committed clustering.

**Vector search angle:** Suggests a principled trigger for when a streaming IVF index should split or merge partitions as inserts drift, instead of fixed size thresholds.

### [Incremental Roseland: Batch-wise Landmark Diffusion via Kernelized Sequential Karhunen--Loève Update](http://arxiv.org/abs/2611.23414)
_Jeanie Schreiber | 2026-11-17 | arXiv (cs.LG) | ⭐_

Makes landmark diffusion maps single-pass and bounded-memory by updating a kernelized SVD as new data rows arrive. A forgetting factor tracks drifting distributions.

**Vector search angle:** Shows how to update landmark-based spectral embeddings in one pass with bounded memory, which could inform streaming updates to learned projections or partitioning under data drift.

## Correctness, benchmarking and memory-hierarchy systems

### [Errpedia: Is Your Exact $k$-NN Vector Search Really Exact?](http://arxiv.org/abs/2611.22474)
_Yinuo Deng, Ying Zhang, Hanchen Wang et al. | 2026-11-17 | arXiv (cs.DB) | ⭐⭐⭐_

A dataset of 1,616 queries across 21 floating-point error categories, with ground truth verified using exact rational arithmetic. All 20 tested library and database configurations returned incorrect top-10 sets on at least one applicable query. Failures range from misranked near-ties to one library omitting all 10 exact matches and several returning fewer than k results.

**Vector search angle:** Add it to your test suite to catch overflow and rounding bugs in SIMD distance kernels and flat search, and re-examine how recall ground truth is computed.

### [Revisiting Index Performance under High Cache-Miss Penalties](http://arxiv.org/abs/2611.21835)
_Mathew M. Kim, Beomseok Nam | 2026-11-16 | arXiv (cs.DB) | ⭐⭐_

AuxBench evaluates byte-addressable indexes as one step inside larger application workloads rather than in isolation. Memory activity after the lookup can reorder which index wins, concurrency-focused designs can lose their edge, and bursty request arrivals cause severe tail latency near saturation.

**Vector search angle:** A methodology warning for ANN benchmarking: closed-loop QPS runs that ignore reranking, payload fetch and open-loop arrivals can mislead index choices on CXL or tiered-memory hardware.

### [Neural Memory Orchestration](http://arxiv.org/abs/2611.23857)
_Michael Zizov, Boris Morose | 2026-11-18 | arXiv (cs.LG) | ⭐_

Overseer collects page faults with eBPF, predicts future pages with a transformer running on remote inference hardware, and has a kernel component map those pages in before they are touched. It cuts runtime by about 35% on Hilbert-curve traversal and by roughly 10x on dense matrix multiplication.

**Vector search angle:** Learned prefetching aimed at irregular, data-dependent page access could help mmap'd disk graph indexes, where traversal page faults defeat the kernel's stride-based readahead.

### [XM-Sparse: High-Throughput Sparse-Attention LLM Serving over Scale-up Memory Pools](http://arxiv.org/abs/2611.22280)
_Yijun Sun, Xudong Liao, Zhuobin Huang et al. | 2026-11-17 | arXiv (cs.LG) | ⭐_

Offloads both the KV cache and the sparse-attention indexer keys to a scale-up memory pool, matching each to its access pattern. On-demand KV fetches are pipelined with attention via TMA, and the predictable indexer-key pages are prefetched with GPU-initiated DMA. Decode throughput rises up to 4.98x over PCIe-based offloading.

**Vector search angle:** Sparse attention here is essentially top-k retrieval over keys, and serving it from pooled memory with fused fetch-and-compute is a template for GPU search over vectors that do not fit in HBM.

### [Every Query Routes Itself: Accelerating Video Diffusion Transformers with Per-Query Routed Sparse Attention](http://arxiv.org/abs/2611.24479)
_Zhen Huang, Shuwei Li, Ruizhe Yao et al. | 2026-11-18 | arXiv (cs.LG) | ⭐_

Clusters only the keys and lets each query pick its own key clusters, standing in for the unselected clusters with their centroids. Queries with identical selections are batched into dense tasks. It reaches 1.66–2.10x end-to-end speedup on video diffusion models with near-dense quality.

**Vector search angle:** This is IVF probing inside attention; executing per cluster and grouping queries by identical probe lists is a usable batching trick for GPU IVF search.

### [RISA: Recoverable Sparse Attention for Block-Diffusion Language Models](http://arxiv.org/abs/2611.22191)
_Xinrui Zhong, Fanjiang Ye, Yuke Wang | 2026-11-17 | arXiv (cs.LG) | ⭐_

For block-diffusion LMs, builds one bounded page read plan per block from seed queries and reuses it across denoising steps, splitting history into priority and recovery tiers instead of evicting it. Attention speeds up 2.67x at 32K and 5.53x at 128K context.

**Vector search angle:** Sharing a single page read set across correlated queries resembles batched beam search on disk indexes, where unioning page reads across queries amortizes I/O.

## Embedding upgrades and what gets stored

### [When the Bill Falls: Reusing the Old Index Defers,Never Avoids, Re-encoding in Complete Embedding-Model Migration](http://arxiv.org/abs/2611.20702)
_Nannan Zhao, Jiameng Zhang, Taoyu Zhong et al. | 2026-11-16 | arXiv (cs.IR) | ⭐⭐_

Across 16 model pairs (plus 11 on NQ), reusing the old index through adapters or window re-ranking never avoids re-encoding a corpus that must fully migrate; it only shifts when the cost is paid. Adapters barely beat the old model. The cost of re-ranking a window can be predicted from the old index alone, which yields rules for planning a migration.

**Vector search angle:** Practical guidance for engines offering model-upgrade workflows: budget for full re-indexing, and use the depth rule to size the interim re-rank window.

### [VIBRA: Backward-Compatible Cross-Modal Retrieval with Consensus Barycenters](http://arxiv.org/abs/2611.23606)
_Shubing Yang, Xutong Liu, Dongfang Zhao | 2026-11-17 | arXiv (cs.IR) | ⭐_

Trains a new encoder whose queries work against a gallery encoded by the old model, inheriting a consensus barycenter of several model views. It is the best compatible method in all 50 CLIP, MetaCLIP and SigLIP2 upgrade settings, adding under 1 ms of query latency.

**Vector search angle:** Backward-compatible query encoders let a deployed index and its quantization codebooks stay in place through a model upgrade, though the migration paper above argues this only defers re-encoding.

### [LoCaR: Localized Canvas Retrieval With Frozen Vision-Language Model](http://arxiv.org/abs/2611.22131)
_Rahim Hossain, Dipanwita Saha, Ashirbad Mishra et al. | 2026-11-17 | arXiv (cs.LG) | ⭐_

A training-free method that segments object regions with SAM2 and encodes each region with a frozen VLM to improve text-to-image retrieval of small objects. It also releases LOCFG, a benchmark for localized retrieval.

**Vector search angle:** Storing several region vectors per image turns image search into multi-vector search, raising index size and per-document aggregation (max-over-regions) as engine concerns.
